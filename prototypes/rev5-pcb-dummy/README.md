# Rev5 PCB outline dummy (PLA)

**WIP - NONFUNCTIONAL VISUAL DUMMY; NOT ASSEMBLY OR SAFETY APPROVAL.**

[Download the STL](board-dummy.stl) | [Self-contained OpenSCAD source](board-dummy.scad)

Bare-board outline: **150 x 95 mm**, nominal visual thickness **1.6 mm**,
with **four nominal 2.7 mm mounting holes**. No electronics, copper or
connector features are included.

This is an outline/hole-location dummy only, not production PCB data or a
load-bearing fixture. It does not qualify actual fit, strength, assembly
height, print readiness or safety, and does not change any design gate.

## Bambu Studio

Intended for a Bambu Lab P1S with PLA. Select your actual nozzle, build plate
and PLA profile in Bambu Studio; do not assume the defaults match your setup.
Import in **mm**, use **100% scale**, place the flat **XY face** on the build
plate, and preview all four holes before deciding to print.

No G-code generation, printer upload or print start was performed for this
bundle.
