## Why this citation

Real, currently-listed M2.5 pan-head Phillips machine screw matching
MH1's 4x M2.5 mounting holes (`MountingHole_2.7mm_M2.5`, no electrical
net). **Material is nylon, not metal** — flagged explicitly rather than
silently implied as steel/brass: a targeted search for an equally
well-confirmed metal (steel/zinc or brass) M2.5 pan-head screw did not
converge on one specific, confidently-verified DigiKey part number this
session (candidates found were either hedged/uncertain or lacked a
directly-confirmed listing) — rather than cite an uncertain metal-screw
MPN, this record cites the one genuinely confirmed real part, and
discloses the material trade-off plainly. Since MH1 is explicitly generic
hardware with no stated material requirement in the design record, a
nylon screw is a legitimate, real, orderable choice — but a
metal screw is an equally valid substitute at order time if a builder
prefers it (not a blocking distinction for this generic hardware line).
Distinct from `DS-FAST-001` (Ruthex RX-M3x5.7 M3 brass heat-set threaded
insert) — that citation is for the Mechanical discipline's own enclosure
threaded-insert hardware, a different physical part serving a different
purpose (3D-printed-plastic thread reinforcement) than this PCB's simple
through-hole M2.5 mounting screw.
