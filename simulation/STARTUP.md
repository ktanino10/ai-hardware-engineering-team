# 高速回転からの有限制動 — 10秒試行

ユーザー指定の [attitude-control-study](https://github.com/ktanino10/attitude-control-study/tree/a927d1ae3409ba143631077824cdf3c904ea27b9)
を読み、**静止→回転を蓄える→独立したブレーキ→面から辺への起き上がり**を、
事前に辺/頂点へ置くPD試験と分けました。二次資料の理想瞬間ロック/固定支点式を、
自由接触する現在のキューブ全体へそのまま適用していません。

## 実行・閲覧

```sh
cd simulation
.venv/bin/python -m cube_sim startup-suite --allow-proxy --output runs/my-startup-suite
.venv/bin/python -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/runs/my-startup-suite/index.html
```

収録版は `evidence/startup-v2/index.html`。各通常動画は**実時間10秒**で、
10秒間を積分しています。短い動画の繰り返し/静止画追加ではありません。
`brake-detail.mp4` は**100倍スロー**と明記した別動画で、0.1秒の計算区間を
10秒で見せます。どちらも同じ状態記録の該当行を描画します。

| ケース | 変えていない/仮定したもの | 読み方 |
|---|---|---|
| `startup-reference` | 元の240 mm / 1.3 kg数学的基準の質量・慣性 | 実機ではない元の基準で、始動方式だけを追加 |
| `startup-rev5-proxy` | 凍結した240 mm / 3.06428 kg部分固体CAD相当の質量・慣性 | 不完全な実設計プロキシ。電池/完全実装/実ドライバー能力は不明 |
| `startup-mechanism-fixture` | **別の100 mm / 0.34 kg合成モデル**。本体0.1 kg、各0.08 kgの環状輪、外/内半径40/35 mm、厚さ4 mm、摩擦係数1.2を仮定 | 機構を観察するための数学的例。Rev5でも記事の実機レプリカでも、採用部品/材料の提案でもない |

合成の環状輪は `Iaxis=m(Ro²+Ri²)/2`、`Itransverse=Iaxis/2+mh²/12`。
実機プロキシの慣性を都合よく増やしたのではなく、別ケースとして明示しています。
面が浮く、辺付近を通る、全コーナーが床から離れる、安定して倒立する、は別の事象です。
表示上の微小離床判定は「荷重接触なし＋最下コーナー>0.1 mm」であり、実測精度や
大きな跳躍を保証しません。捕捉制御や2回目の頂点への跳躍は未実装です。

## 調整するのは実在するモデル入力

`models/startup-*.json` は再現可能なパラメータファイルです。比較はコピーした新しい
ケース名で行い、凍結済みの入力/証拠や実機のSource of Truthを書き換えません。

- `scenario.startup.target_rad_s`: 各ホイールの符号付きXYZ目標。0の軸は駆動しない。
- `actuation.torque_limit_nm`: 各軸の理想モーター上限。
- `actuation.independent_brake.capacity_nm`: 各軸の独立ブレーキ上限。
- `scenario.startup.engagement_delay_s` / `ramp_s`: 仮定した指令遅延/トルク上限の立ち上がり。
- `contact.sliding_friction`: 未同定の床摩擦。変更した比較は仮定条件として扱う。

**キューブに上向きの力やXYZの外部インパルスを直接加えません。**
モーターは内部hingeトルク、ブレーキは同じhingeの有限なdry-friction制約です。
床のXYZ反力・外部角力積は結果として計算されます。速度のリセット、固定ピボット、
姿勢補正で起き上がったように見せる操作はありません。

3000 rpmは提供済みの旧解析にある**目標値のみ**で、安全/定格RPMではありません。
標準プログラムは3秒まで回転指令、3.5秒でブレーキ指令、仮定した20 ms後から
1 msで上限を立ち上げます。上限 `Iaxis*target_omega/5 ms` は**仮想比較条件**で、
5 ms停止を強制していません。実際のモデル内停止時間を相対速度<1 rad/sで記録します。
DRV10983の実際のBRAKE機能・電流・再起動・回生・保持・遅延を確認したものではありません。

## 仕事・角運動量と刻み/出力頻度

R1の `SIM-R1-001` は、RK4の4評価点に対して仕事だけ端点台形則だった問題です。
補正後は**実際の4状態を読み取り専用で記録し、別のMjDataで力を再評価して
RK4重み1:2:2:1で積分**します。軌道を書き換えず、従来の転倒軌道が同一であることも
比較します。最大（全積分ステップ/記録グリッド）と最終残差、方法と未校正状態を
`summary.json` に記録します。残る積分器/ソルバー誤差を消したり閾値で隠したりしません。

始動試験の刻みは0.1 ms、通常記録は10 ms、制動窓3.48〜3.60秒は0.1 ms記録。
0.05 msへの刻み変更と1 msへの出力間引きを別々に比較します。
`brake_work` は**拘束仕事の内数**であり、エネルギー収支へ二重に足しません。
床接触による機体への仕事は拘束仕事−ブレーキ仕事、全体のCOM角運動量変化は
床からの外部角力積と比較します。仮想ブレーキの散逸を実機の温度/強度へ読み替えません。

[Blender](blender/README.md) は同じ軌道の別描画、
[CERN ROOT](root/README.md) は列指向データ交換/時間重み付き解析に使います。
いずれも実機/Fusion承認ではありません。R1の短い14ケースは
`evidence/initial-v1/` に歴史的証拠としてそのまま保存し、
始動・会計補正・Blender・ROOTは別の版で独立レビューします。
